# A Letter to My Future Self

Interactive one-page presentation for an English class: dreams, career, and travel.

## Develop

```bash
npm install
npm run dev
```

## Replace images

1. Add photos to `public/images/`
2. Edit the paths in `src/content/images.ts`

Suggested filenames:

- `introduction.jpg`
- `career.jpg`
- `japan.jpg`
- `lifestyle.jpg`
- `goals.jpg`
- `conclusion.jpg`

Until a file exists at that path, a styled placeholder is shown.
